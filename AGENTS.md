# Agent instructions

This repository is a field kit inspired by Tony Fadell's *Build*. It is questions and templates, not an application. Do not add product code unless someone asks.

## How to run a skill

Skills live in `.cursor/skills/<name>/SKILL.md`. Templates live in `templates/`.

When someone says `run <name>`, names a skill, or asks to vet an idea, read that `SKILL.md` and follow it. Do not improvise a shorter version.

Start with `.cursor/skills/worth-making/SKILL.md` unless they named another skill.

Interview them. Do not invent customers, pain, traction, or a why. If they do not know, write `unknown`.

Save product briefs in `ideas/`. Save career, hiring, CEO, and board briefs in `career/`. Use the template the skill names.

Do not quote or copy chapter text from *Build*.
